# Excel-data-cleaning-project
data cleaning and analysis project using Microsoft Excel
## Project Overview

This project focuses on cleaning, validating, and analyzing e-commerce sales data using Microsoft Excel.

## Dataset

- 5,000+ sales records
- 12 columns
- E-commerce sales transactions
- Includes order, customer, product, payment, delivery, rating, and revenue data

## Data Cleaning

The dataset was reviewed and cleaned to improve data quality and consistency.

Main steps included:
- Checking for missing values
- Validating data types
- Checking numerical ranges
- Identifying unusual records
- Validating revenue and sales-related fields

## Analysis

The cleaned data was analyzed using Excel PivotTables and charts to identify:

- Sales performance by product category
- Sales performance by region
- Orders and revenue by year
- Customer ratings
- Delivery performance
- Payment methods

## Tools

- Microsoft Excel
- PivotTables
- Charts
- Data Validation
